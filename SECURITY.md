# Security Policy

## Supported Versions

Security fixes target the latest published release.

## Reporting A Vulnerability

Report vulnerabilities privately through [support@xquik.com](mailto:support@xquik.com).

Do not open public issues for secrets or private data exposure. This rule also covers package supply-chain concerns.

We aim to acknowledge reports within 3 business days. We coordinate disclosure after confirming the issue.

## Scope

Report defects in credential handling, requests, response parsing, dependencies, generated code, or release metadata.
